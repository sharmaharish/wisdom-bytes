# Research: Existing Projects & Content Sources

## GitHub Repositories

### dwmkerr/hacker-laws
- **URL**: https://github.com/dwmkerr/hacker-laws
- **Description**: 50+ laws, theories, principles, and patterns for developers/technologists
- **Format**: Single README.md with detailed descriptions
- **Topics covered**: 90-9-1 Principle, Amdahl's Law, Brooks' Law, CAP Theorem, Conway's Law, Dunning-Kruger, Dunbar's Number, Fitts' Law, Gall's Law, Goodhart's Law, Hanlon's Razor, Hofstadter's Law, Hyrum's Law, Jevons' Paradox, Kernighan's Law, Moore's Law, Murphy's Law, Occam's Razor, Parkinson's Law, Putt's Law + many more
- **Extra**: Available as PDF eBook, has translations

### clementroche/laws
- **URL**: https://github.com/clementroche/laws
- **Description**: Collection of inspirational laws from several domains — economics, psychology, computer science, sociology
- **Format**: Single README.md

### henu-wang/awesome-mental-models
- **URL**: https://github.com/henu-wang/awesome-mental-models
- **Description**: Curated list of mental models, heuristics, intuition pumps
- **Focus**: Economics, Psychology, Biology, Chemistry, Physics, Engineering, Mathematics
- **Format**: README with categorized links

### Arigitshub/mind-models
- **URL**: https://github.com/Arigitshub/mind-models
- **Description**: Open standard for psychological models, cognitive frameworks, behavioral patterns
- **Format**: Structured Markdown (one file per model), machine-readable
- **Structure**: Category, Origin, Tags, Description, Examples, Related models
- **Categories**: cognitive, behavioral, social, emotional, decision, developmental

### jacksonshapiro11/mental-models-observatory
- **URL**: https://github.com/jacksonshapiro11/mental-models-observatory
- **Description**: 119 mental models across 40 knowledge domains (Next.js app)
- **Format**: TypeScript/JSON source of truth, markdown content files

## Key Takeaway
Several excellent collections exist but none combine ALL categories (laws, mental models, biases, fallacies, paradoxes) in a simple text-file format designed for terminal display. The wisdom-bytes project fills this niche perfectly.
