# Wisdom Bytes - Rough Idea

Create a knowledge base of engineering laws, mental models, principles, paradoxes, cognitive biases, patterns etc. - basically meta wisdom acquired by humanity over centuries.

## Reference Websites
- fs.blog
- lawsofengineering.com
- untool.co

## Core Requirements
- A shell script that automatically picks 1 concept from this knowledge base whenever a new shell is created
- Shares the concept with an example explaining it
- The knowledge base should be a git repository for GitHub
- Extensible with new resources and concepts
- Concepts stored in simple text files for readability
